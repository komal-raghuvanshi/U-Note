# U-NOTE frontend

The React + Vite frontend is part of the U-NOTE platform. Start the Flask API before using database-backed views, configure `VITE_API_BASE_URL` when the API is not at `http://127.0.0.1:5000`, then run:

```powershell
npm install
npm run dev
```

See the repository [README](../README.md) for database configuration, migrations, authentication, and validation commands.
